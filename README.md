# Chess Puzzle Classroom

A Flutter application designed for chess teachers and students. Teachers can create virtual classes, invite students and assign chess puzzles, while students can solve the puzzles and track their results.

## Features

- User registration and authentication
- Teacher and student roles
- Creation and management of chess classes
- Student invitations and class membership management
- Creation of custom chess puzzles
- Interactive chessboard for solving puzzles
- Tracking of completion time and number of attempts
- Individual student statistics
- Overall class and puzzle statistics
- Firebase-based data storage and authentication

## Technologies

- Flutter / Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- GetX

## Purpose

The goal of the project was to create a practical tool for chess education where teachers can organize students into classes, assign interactive chess puzzles and monitor their progress.
